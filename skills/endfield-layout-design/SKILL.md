# Endfield Layout Design

学习官方物料的构成方法，服务用户的内容。先定信息结构，再选视觉家族；配色不等于风格。本包的数字与字体建议是研究归纳或原创制作默认值，不是官方规范。

## 制作流程

1. 提取用户提供的文案、事实字段、素材、尺寸和用途。保留人名、数字、日期、限制条件与素材主体；只调整断行和层级，不擅自删改。缺少尺寸时：竖海报 1200×1600、信息卡 1200×900、页面以 1440px 桌面和 390px 手机作为检查点。缺少图片时用自制几何图或明确的占位图；未知日期/地点写「待定」，不虚构。
2. 阅读 [排版规则](references/layout-rules.md)；从 [典型构图](references/compositions.md) 选择一种主构图。按需查看 [逐图分析](references/visual-analysis.md)，实际打开 2—3 张相关参考图。出处在 [来源索引](references/sources.md) 和机器可读 [source-index.json](references/source-index.json)。优先跨月份比较，避免把单一版本当成完整品牌。
3. 给出简短设计说明：阅读顺序、图文位置、所用参考 ID、主题色选择和字体替代。常规任务随说明继续制作；只在缺少会实质改变结果的信息时提问。用户的品牌色、Logo、尺寸和素材优先于本包建议。
4. 建立共享对齐线，把标题、正文、编号和标签放到同一模块体系。保留完整、可读的文字区；主题色从素材或用途选择。仅在需要时采用大幅英文、几何纹理或编号，不编造无意义参数来装饰。
5. 输出可编辑源文件和渲染图。示例用法与离线辅助脚本见 [制作与验证](references/production.md)。脚本是两类构图的起点，不能代替针对内容的设计；其他构图可用 SVG、HTML/CSS 或用户指定工具实现。
6. 在全尺寸与目标显示尺寸查看渲染。长标题/正文先扩展模块、减少装饰、改变分栏或加续页，再合理缩字号；固定画布仍装不下时说明并交付完整内容的续页，不隐藏、截断或省略事实。修改后重渲染有变化的成品。

## 布局选择

- **形象海报**：一幅主视觉＋独立标题/行动信息区。参考 R14/R25/R34/R36 的主体与信息分区，或 R17 的黑白大图与留白。没有人物也可用产品、建筑或自制图形。
- **活动横幅**：图像重心与高对比标题相对，参考 R03/R12/R21/R24/R30；从文案长度决定左右关系，不能把人物位置固定为右侧。
- **资料卡/说明页**：主题色头部＋白底正文＋统一标签/细线，参考 R15/R26/R35/R37。多字段使用 R09/R22 的标签—值结构。
- **页面/长图**：重复章节与图文模块，参考 R07—R09、R22、R32—R33；手机端折为单栏，正文自然增长，装饰不占阅读宽度。

## 自检

- 内容核对：所有用户文案和关键字段都可见，英文有真实含义；未获准的翻译不替换原文。
- 层级核对：缩小后先看见主题，再看时间/行动，再读细节；英文辅助信息不抢中文主题。
- 几何核对：检查边界溢出、重叠、基线、模块间距、图像裁切及人物脸/产品特征。背景装饰可出血，事实文字不能。
- 可读核对：正文/背景对比建议至少 4.5:1，大标题至少 3:1，这是本包的可读性标准；不要把样本里的低对比微字用于必要信息。
- 克制核对：每处线、编号、标签或几何有明确作用；装饰盖住内容就删。不要同时堆叠多套官方物料的装饰。
- 来源核对：研究图仅供参考；除用户明确提供并要求使用外，不把官方 Logo、角色、文案、版权落款固定嵌入输出，不冒充官方作品。合作图 R38—R40 的合作方视觉属于特例。
- 交付核对：确实渲染、打开并修正后才能报告完成；列出参考 ID、字体替代、验证情况和未验证项。
