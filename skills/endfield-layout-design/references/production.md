# 制作与验证

## 输出与默认值

默认交付 PNG＋可编辑 SVG；页面交付 HTML/CSS 和实际尺寸预览。字体优先使用用户指定且本机存在的字体。示例使用 Windows 的微软雅黑、宋体和 Arial，属于本包替代字体，不是确认的官方字体。跨机器重渲染应检查字体存在；不能只靠 SVG 的回退声明判断中文已经显示。

研究图位于 `assets/official-references/`，只用于观察。`assets/primitives/` 的素材为本包自制。示例不导入任何官方角色、Logo 或宣传文案；原创占位图不是用户将来必须采用的视觉。

## 离线辅助脚本

`scripts/render_examples.py` 需要 Python 3 和 Pillow。复用本机已有环境，不需要 AI 服务或联网。默认一次产生短/长文案各两种设计，保留 JSON 文案、SVG 源文件、PNG 与文字边界检查报告：

```powershell
python scripts/render_examples.py --out "C:\your-output\endfield-examples"
```

可通过 `--spec input.json` 替换示例文案。输入结构参考 `assets/examples/example-spec.json`。脚本支持固定的原创示例构图；用户提供复杂图像、其他比例或页面时，应根据构图说明独立制作，不机械套用它。文字装不下会明确报错，不会吞字。示例源 SVG 在其他编辑器中打开可能因字体度量略变，应在该编辑器中复验。

## 验证顺序

1. 对照输入逐项检查主题、时间、地点和所有正文/限制条件。
2. 检查真实字体下的文字测量、可见区域边界和模块相互重叠。
3. 查看全分辨率 PNG 与缩至 600px 宽的预览；文字应有稳定阅读顺序。
4. 用较长标题和正文替换，允许模块高度变化；核实没有删文、隐文或挤压事实字。
5. 记录本次实际运行的检查，区分自动几何检查与人工视觉查看；格式验证只验证 Skill 文件，不证明设计质量。

当前示例结果与发现记录在 [验证报告](validation.md)。
