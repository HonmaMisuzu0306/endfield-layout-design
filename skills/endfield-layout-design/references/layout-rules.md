## 建议尺寸关系（原创制作默认值）

以画布短边 S 为尺度：外边距 0.05—0.07S；正文 0.023—0.03S；小型辅助信息 0.016—0.021S；主标题约正文的 2—3.5 倍；正文行高 1.45—1.65。这些数字是适合开始排版的范围，源于样本分区观察与可读性要求，未宣称为官方量化规范。最终按目标显示尺寸、用户文案和字体实测调整。

## 配色模式

- 浅色资料型：R15/R26/R35/R37。浅底保障正文，主题色聚在头部或细条。
- 场景横幅型：R03/R12/R21/R24/R30。用深色渐变/实底托标题；强调色与主视觉匹配。
- 章节说明型：R07—R09/R22/R32—R33。重复内容板块，主题色主要作为章节导航。
- 独立活动型：R10/R17。形式弹性较大，只借层级与空间关系，不把特例当通用模板。
- 合作型：R38—R40。来源仍是游戏官号，但相当部分形状、字形和色彩来自合作方，应与游戏内部模板分开研究。
