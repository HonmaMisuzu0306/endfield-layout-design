# 典型构图

坐标为画布归一化范围，属于可调起点。与位图的区块观察相呼应，并非官方坐标。最终仍以用户内容和视觉实测为准。

| 类型 | 参考 | 结构与阅读方向 | 变体与边界 |
|---|---|---|---|
| A 主体海报 | R14、R25、R34、R36 | 上部主视觉占高约 0.6—0.75；下方名字/主题与短资料；正文与图像之间保留浅色过渡。 | 强调人脸/产品轮廓；底部信息增加时提高信息区，减少主图高度；不复制角色专属名字字形。 |
| B 反差活动海报 | R17 | 上部大视觉与黑色块；下方留白承托标题、日期和地点；一个强烈几何母题统一主图。 | 环形视觉是演出特例，其他活动用自己的图像主题。无素材时可自画几何装置。 |
| C 横向活动横幅 | R03、R12、R21、R24、R30 | 图像约宽 0.55—0.7；标题占另一侧并置于稳定明暗区域；类别与时间在标题邻近。 | 图文可左右互换。长标题分两行或扩大实底，不盖脸。 |
| D 资料卡 | R15、R26、R35、R37 | 上部约高 0.35—0.5 为主题/轮廓区；下方单栏正文；小黑条标明语录/字段；一组共享左边线。 | 卡片不一定需要人物；文字多时压低头部装饰高度，优先保留行高。 |
| E 章节说明 / 页面 | R07—R09、R22、R32—R33 | 章号＋标题条；白底内容；同宽插图；字段标签—值；模块纵向重复。 | 桌面可两栏但手机单栏。每章高度随内容增长；不要把整个长图缩成一页不可读海报。 |
| F 时间表 | R01、R23 | 日期坐标固定；任务彩条占对应时段；起止时间与事件名都有明确归属。 | 优先数据正确；密度大时扩大画布或分时段，不能用色条替代必要文字。 |

## 适配步骤

短文案：保持主图与留白，避免为了「填满」而增加假标签。

长文案：先确定主题、时间、地点/行动、条件与细节的阅读顺序。允许换行与纵向增高；固定尺寸先减少主视觉，再改变栏数，再微调字号。如果仍不足，拆为主海报＋说明卡或续页，所有原文保持可见。

用户已有素材：以原图宽高比、主体安全区域决定构图，不强行套固定图框。需要裁切时保留主体关键特征；源文件引用或嵌入用户原图，记录裁切范围。

## 页面检查

用语义化标题和真实按钮/链接，保持键盘可操作；日期和状态可复制。把重复信息模块变成内容流，不硬编码成海报里的绝对坐标。390px 屏宽下正文建议至少 16px，装饰出血不能造成横向滚动。此项是本包页面制作建议，未把宣传图反推成官方网页规范。
